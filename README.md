# Deying-Ai

> 把复杂问题，变成简单好用的产品。

**当前聚焦：** AI-native profile  
**所在地：** Remote  
**状态：** <strong>开放交流</strong>

## 个人主页 / Profile Site

这个仓库同时包含一个可直接部署到 GitHub Pages 的 AI 原生个人档案：

- 动态关系图主视觉
- 本地运行的档案问答，不上传个人信息
- 桌面与移动端响应式布局
- 修改 `profile.config.json` 后运行 `npm run build` 即可同步 README 与网页内容
